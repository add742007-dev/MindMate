# MindMate

MindMate is a simple Python-based self-reflection program designed to help users organize their thoughts, separate facts from assumptions, and look at situations from different perspectives.

## Features

- User name input
- Situation and interpretation recording
- Emotion selection
- Belief-strength rating from 1 to 10
- Evidence checking
- Fact vs. assumption identification
- Rule-based situation analysis
- Emotion-based reflection
- Final reflection suggestions
- Command-line based execution

## Requirements

- Python 3.14.7
- No external Python libraries are required

## How to Run

1. Install Python 3.14.7 or a compatible Python 3 version.
2. Download or clone this repository.
3. Open the project folder in a terminal or VS Code.
4. Run the program using:

python main.py

## How to Use

1. Enter your name.
2. Describe what actually happened.
3. Describe what you think the situation means.
4. Select your current emotion.
5. Rate how strongly you believe your interpretation from 1 to 10.
6. Indicate whether you have clear evidence supporting your interpretation.
7. Identify whether your interpretation is a fact, an assumption, or a mixture of both.
8. Read the reflection and analysis provided by MindMate.
